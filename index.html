FEATURES

核心特性

Phase 1（托盘+检索+Agent）+ Phase 2（知识图谱）已完成

📚

双层知识库

L1 规范/记忆/索引层（CLAUDE.md 模式，启动注入）+ L2 内容层（按需检索）。INDEX.md 自动生成。

🔍

ripgrep 全文检索

内嵌 ripgrep 内核：多关键词任一命中、智能大小写、小节上下文（section/context）。

🕸

SQLite 知识图谱

[[双向链接]] 解析、反向链接、孤立文档检测、标签/项目维度统计——关联可审计、可追溯。

🤖

LLM 代理 + 流式

OpenAI 兼容（Ollama / DeepSeek 等），后端代理防 CORS 与密钥暴露；SSE 流式透传。

💬

Agent 问答回路

启动注入 L1 → 提取关键词 → 检索 L2 → 拼 Prompt → 流式回答，回答带 [文件:行号] 引用；会话内 4 轮记忆。

📋

写回沉淀 · 待审

LLM 生成的新知识先进 pending/，/approve 确认后落地（自动重建 INDEX+图谱），不污染知识库。

🖥

托盘常驻

tray-icon + winit，右键菜单：打开终端 / 同步索引 / 退出。release 单 exe，双击即用。

⌨️

网页终端

xterm.js 富渲染：标题加粗、行内代码、[[双链]] 着色、表格保留 | 结构、frontmatter 变暗。

ARCHITECTURE

四层架构

01

常驻底座层

Rust 托盘常驻 + Axum 本地服务（127.0.0.1，同源托管前端免 CORS）

02

知识内核层

双层 MD 布局 / frontmatter 解析 / INDEX 自动生成 / 路径安全

03

检索引擎层

ignore 遍历 + grep crate（内嵌 ripgrep），行级小节切分

04

交互层

xterm.js 网页终端（Agent 回路 + 管理命令 + 配置页）

QUICK START

快速开始

# 从源码运行（托盘模式）
$ cargo run
# 纯服务模式（调试） / 自定义端口
$ cargo run -- --no-tray
$ cargo run -- --port 9000

# 浏览器打开可视化配置页，填写 endpoint / model / api_key
http://127.0.0.1:8756/config.html

# 直接输入问题走 Agent 问答；常用命令：
> /search 关键词      # 全文检索（显示所属小节）
> /graph 路径        # 知识图谱：出链 / 入链 / 关联簇
> /digest 主题       # 检索结果整理成结构化笔记
> /pending           # 查看待审 → /approve 落地
> /help              # 全部命令
