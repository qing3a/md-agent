# 会话记录

## Q: 托盘应用是什么？
A: 根据知识库内容（[工具:search]），「托盘应用」指的是 **托盘 + 本地服务架构**（见 `notes/架构/托盘应用.md`）：

- **核心形态**：一个 Rust 编写的**托盘常驻进程**，内置 **Axum HTTP 服务**；浏览器中的 xterm.js 终端通过 `localhost` 接口来操作知识库。
- **心跳同步**：默认**关闭**；启用后托盘每秒 tick 一次，检测配置（config）文件 mtime 变化并即时生效——无需重启、无轮询延迟感。可通过托盘勾选、命令、配置页三个入口开启。
- **检索实现**：本知识库的实际检索（ignore 遍历 + grep crate 匹配，内嵌 ripgrep 内核）也落在该应用中，方案详见 [[无向量库检索]]。

它本质上是知识库的「本地宿主」——让桌面托盘程序与本地 Web 服务结合，作为操作知识库的入口载体。
