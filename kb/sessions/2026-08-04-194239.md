# 会话记录

## Q: 检索引擎用什么实现
A: 检索引擎用的是**内嵌 ripgrep**（Rust 的 `grep` + `ignore` crate），**不引入向量库**。这是 2026-08-02 项目启动时定下的方案 [MEMORY.md:14]。

具体实现要点 [notes/rag/无向量库检索.md:16，notes/架构/托盘应用.md:13]：

- 使用 ignore crate 遍历文件（可自动尊重 `.gitignore`），grep crate 做关键词匹配
- 支持 smart case、多关键词任一命中
- 按文件 + 行号返回命中片段，命中文件再按 `#` 标题定位上下文
- 实际落点在 Rust 托盘应用（tray-icon + winit 主线程）内，经 Axum HTTP 接口暴露给 xterm.js 终端
- 适用边界：不解决同义/语义召回，查询词需与正文措辞一致
