# 托盘 + 本地服务架构

一句话摘要：Rust 托盘常驻进程内置 Axum HTTP 服务，浏览器 xterm.js 终端通过 localhost 接口操作知识库。

## 链路
系统托盘（Rust）→ 浏览器 xterm.js 终端 → Fetch(localhost) → Axum 接口 → 检索引擎/文件读写 → 本地 MD

## 组件
- 托盘：tray-icon + winit 事件循环（主线程）
- 服务：Axum + tokio（后台线程），127.0.0.1 绑定
- 检索：ignore 遍历 + grep crate 匹配（内嵌 ripgrep 内核），方案见 [[无向量库检索]]


## 心跳同步（托盘常驻实现）

- **定位**：默认**关闭**；启用后托盘每秒 tick 一次，检测 config 文件 mtime 变化 → 即时生效（无轮询延迟感、无重启）
- **三入口**：托盘勾选项 / 命令 / 配置页（默认关，用户显式开启）
- **实现**：tray-icon + winit 事件循环主线程内跑 ticker；mtime 比较基于 config.json 文件时间戳
- **坑（2026-08-03 定位修复）**：muda 0.19 `CheckMenuItem` 的 `with_id` 参数顺序是 **(id, text, enabled, checked)**——曾把勾选态误传进 `enabled`，导致关闭态整项原生置灰、点击无反应；修复后经 UIA 自动化双向验证（勾选/取消均正确）
