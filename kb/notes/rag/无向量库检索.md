# 无向量库检索

一句话摘要：用 grep + ignore 做纯文本检索，替代向量库，适合小规模本地 MD 库。

## 思路
- 关键词智能匹配（smart case、多关键词任一命中）
- 按文件 + 行号返回命中片段
- 命中文件再按 `#` 标题定位上下文
- 本库的实际检索实现见 [[托盘应用]]（ignore 遍历 + grep crate）

## 适用边界
- 不解决同义/语义召回：查询词需与正文措辞一致
- 库规模大或需要语义检索时，可后续叠加 embedding 层（可选）
